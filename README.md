
# PechAI: Hybrid Recommendation System

This is a hybrid recommendation system for urban farming industry. This generates recommendations based on near real-time data that are captured through various sensors, paired with weather API, rule-based engine and LLM-enchanced recommendations.


## Installation

Install Java Development Kit (JDK), maven, ngrok and ollama on the terminal.

For arch systems:

```bash
    paru -Syu jdk mvnvm ngrok ollama
```
For yay package manager.
```bash
    yay -Syu jdk mvnvm ngrok ollama
```
For windows systems, install Java Development Kit (JDK), maven, ngrok and ollama on their respective download pages.
